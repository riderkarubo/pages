SEC. 00

結論だけ先に

迷ったらこの3行に戻ってください。

  1. 技術より先に「会社ごっこ」を決める。明和電機が強いのは装置そのものより、青い作業服と「製品」「製品デモ」という額縁です。装置単体は必ず滑ります。世界観のフォーマットが笑いを支えます。
  2. 最初の1台は「首を振る／音が出る／光る」の3つだけでいい。M5Stack＋サーボ1個＋スピーカー。ここに音声AIを載せた瞬間、既に舞台で成立する装置になります。実際にオープンソースの完成形（スタックチャン）が存在するので、それを土台に改造するのが最短です。
  3. 舞台は探すのではなく、既にある。「技術力の低い人限定ロボコン（ヘボコン）」はヘボさがルール、Maker Faire Tokyo は個人出展可、アマチュアお笑いライブはエントリー制。3ヶ月後の出番を先に予約してから作り始めるのが正解です。

SEC. 02

部品表：装置は4系統でできている

全部を一度に学ぼうとすると必ず折れます。装置を4つの系統に分けて、下から順に手をつけてください。

系統役割まず触るもの学習コスト備考
① 神経
マイコン		 センサーを読み、モーターを回す。装置の中枢。 M5Stack系（CoreS3 / M5StickC Plus2） 低 画面・ボタン・スピーカー・Wi-Fi・バッテリーが最初から入っており、はんだ付けなしで始められる。Arduino互換。
② 筋肉
アクチュエータ		 物理的に動く。首を振る、腕が上がる、蓋が閉まる。 サーボモーター（SG90など）、LEDテープ、小型スピーカー 低 1個数百円。「角度を指定すると、その角度まで回る」だけの部品。最初はこれ1個で十分。
③ 頭脳
AI		 喋る・聞く・判断する。貴殿の既存の強みが直結する層。 VOICEVOX（無料の音声合成）→ OpenAI Realtime API → M5 Module LLM（オンデバイス） 低〜中 Realtime APIは音声→応答→音声を1本のWebSocketで処理する。従来の3段パイプラインが不要になった。
④ 外装
ガワ		 見た目。舞台上ではここが8割。 ダンボール・ホームセンター素材 →（必要なら）3Dプリンタ 中 3Dプリンタは急がない。Bambu Lab A1 mini などが3万円前後まで下りてきているので、必要になってから買えばよい。

※ 回路設計・基板設計（KiCad等）は当面不要です。ブレッドボードとM5Stack用のコネクタ（Grove）で、はんだごてを握らずに済む範囲がかなり広い。

SEC. 03

工程表：3ヶ月で舞台まで

順序に意味があります。飛ばすと必ず「動かない箱」で止まります。

00WEEKEND

光らせる・動かす

所要：週末2日／費用：約1万円

M5StickC Plus2にサーボ1個をつなぎ、ボタンを押すと首が振れる状態を作る。プログラムはAIに書かせて構いません。ここでの目的は理解ではなく「自分の手元で物が動いた」という事実です。

  • M5Stack公式の日本語ドキュメントで開発環境（Arduino IDE）を構築
  • Lチカ（LEDを点滅させる）→ サーボを0度と90度で往復
  • LEDテープを光らせる
GOALボタンを押すと、何かが動いて光る。
01WEEK 1-4

喋らせる ＝ スタックチャンを作る

所要：2〜4週／費用：約2万円

「スタックチャン」はM5Stackで作るオープンソースのデスクトップロボットで、コミュニティがAI連携まで作り込んでいます。公式キットがスイッチサイエンスで販売されており（基本版18,150円）、ゼロから設計する必要がありません。ここを土台にするのが最大の時短です。

  • まず素の状態で動かす（首振り＋表情）
  • VOICEVOXで喋らせる → 次にChatGPT/Realtime APIで返事をさせる
  • 返事の内容を「絶対に役に立たない」方向へ改造する ← ここが芸
GOAL話しかけると、ろくでもない返事をして首を振る。
02MONTH 2

外装を作る ＝ ネタとして成立させる

所要：3〜6週／費用：0〜3.5万円

中身が同じでも、外装で笑いの量が変わります。まずはダンボール・木材・100均で作り、それでも足りなければ3Dプリンタを導入する。3DモデリングはGUIで覚えるよりコードで書くCAD（OpenSCAD / CadQuery / Build123d）をAIに書かせるのが、貴殿の場合は圧倒的に速い。

  • 装置に型番と製品名をつける（例：SUMIMASEN-1号）
  • 説明書・カタログ・シールを作る（ここが世界観の8割）
  • 3Dプリンタは「必要になってから」買う
GOAL写真1枚で何の装置か伝わり、笑える。
03MONTH 3

舞台に載せる

所要：3〜4週

装置が完成した状態と、舞台で動く状態はまったく別物です。ここを甘く見た人が本番で必ず沈みます。

  • 3分の構成を作る（振り→装置起動→期待外れ→オチ）
  • スマホで自撮りして通しリハを最低5回。動かない前提の逃げ道の台詞を用意する
  • 電源・音声出力・照明下での見え方を実会場条件で確認
GOAL装置が壊れても3分間ウケる状態。

⚠ 舞台上でAIを使う者への警告

  • 会場のWi-Fiは信用しない。クラウドAPI（Realtime API等）はネットが落ちた瞬間にネタごと死にます。スマホのテザリングを必ず二重化するか、そもそもオフラインで動く構成にする。
  • オフラインの選択肢は既にある。M5Stackには「Module LLM」というオンデバイスでLLMを動かすモジュールがあり、Arduinoから使えます。ネット不要は舞台では絶対的な強みです。
  • 音声認識は客席のざわつきで落ちる。本番はマイクを装置に近づける、もしくは「自分が手元のボタンで発話タイミングを制御する」設計に逃がす。
  • 応答の待ち時間は舞台では致命傷。2秒の沈黙は舞台では10秒に感じます。待ち時間中に装置が意味もなく回る等、「間」を埋める動作を必ず入れる。
  • バッテリーは本番前に必ず満充電。M5Stackの内蔵バッテリーは実働が短い。モバイルバッテリー給電を標準構成にする。
SEC. 04

AI駆動の作り方：貴殿の勝ち筋

電子工作の学習コストの大半は、AIで消せます。ここが他の入門者との決定的な差になります。

工程従来のやり方AI駆動でのやり方
配線データシートを読んでピン配置を調べる部品とマイコンの写真を撮ってAIに貼る。「このサーボをM5StickC Plus2に繋ぐ配線を教えて」で完了する。
コードArduinoの文法・ライブラリを学習Claude Code等にPlatformIOのプロジェクトごと生成させる。エラーはシリアルモニタの出力をそのまま貼れば直る。
3DモデルFusion 360等のGUI操作を習得OpenSCAD / CadQuery / Build123dはコードで形状を書く方式。AIが直接書けるため、GUI習得を丸ごと飛ばせる。
部品選定電子部品の知識が前提「秋月電子で買える、3V〜5Vで動く、音が出る安い部品」のように条件で聞く。型番まで出させる。
ネタ出しひたすら考える装置の仕様書をLLMに渡してボケを100個出させ、自分は選ぶ側に回る。3案並行で軸を変えるのが効く。
装置の中身if文で条件分岐を書くRealtime APIで装置自体が即興で喋る。台本のない受け答えは、舞台では最大の武器になる。

POINT電子工作の初心者が最初に折れるのは「動かない原因が分からない」瞬間です。貴殿はそこをAIで踏み倒せる。つまり本来なら3ヶ月かかる第0〜1工程を、数週間に圧縮できる立場にいます。逆に言えば、時間を使うべきなのは技術ではなく企画と舞台稽古の側です。

MUGON-0

お題を入力するとAIが本気で最高のボケを生成する。画面に表示される直前、サーボで物理的なシャッターが降りて隠す。観客は永遠に答えを見られない。装置が「今のは相当おもしろかった」とだけ報告する。

構成：M5Stack＋サーボ1（シャッター）＋LLM／笑いの核：見せないという一点だけで成立する構造／最も少ない部品で作れる

進言3案のうち、軸C（MUGON-0）を第1作に推します。部品が最も少なく、AIの出力品質に依存せず（何しろ見せない）、失敗しても構造上ネタが崩れないためです。軸Bは世界観の作り込みに時間がかかるので第2作、軸Aは映像作品として展開する余地が大きいので、動画側の企画と束ねるのが得策かと存じます。
