## 編集作業の手順（MANDATORY）

### 通常の編集フロー

1. **`分科会用資料_20260414.html`（骨子版）を編集する**
2. **`公開版_bunkakai_index.html` にも同じ変更を反映する**
   - `cp` によるファイルごとの上書きは**禁止**（公開版の先頭2行が消えるため）
   - 必ず同じ箇所を個別に Edit で差し替える
3. 公開版の先頭に以下の2行が残っていることを確認する（絶対に消さない）：
   ```html
   <script src="../auth.js"></script>
   <script>document.addEventListener('DOMContentLoaded',function(){FireworkSSO.protect();});</script>
   ```
4. 両ファイルの「最終更新」日時を現在時刻で更新する

### タスクを「完了」にする場合

1. 分科会本体から該当セクションを削除（または `<!-- 完了 -->` コメントアウト）
2. `完了タスク_A5_20260501.html` を参考に、完了タスクアーカイブHTMLに移植する
3. 完了日・反映先を明記する

## よくある落とし穴

- **全角括弧「（）」vs 半角括弧「()」の混在**: HTML内に全角括弧が多い。Edit で old_string をコピーする際は原文の文字（全角/半角）を1文字単位で踏襲すること。2回以上失敗したらファイル全体を Read → Python 一括置換に切り替える
- **骨子版だけ更新して公開版を忘れる**: 毎回必ず両方を更新する
- **SSO 2行の削除**: 公開版の `<head>` 冒頭 2行を誰かが消すと全ユーザーがアクセス不能になる
