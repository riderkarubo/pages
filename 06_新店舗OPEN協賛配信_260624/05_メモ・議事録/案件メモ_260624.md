## プラン構成（2パターン）

### ミニマムパターン: スマホ配信（2名体制）

- 機材: スマートフォン配信・リングライト・ワイヤレスマイク・モバイル回線
- 体制: 制作進行（メインD）+ 現場サポート の2名
- 想定用途: コンパクトに現場の臨場感を届けたいシーン

### リッチパターン: OBS配信（5名体制）

- 機材: 一眼カメラ複数台・OBS・スイッチャー・テロップ・有線LAN前提
- 体制: 制作進行 + 現場ディレクター + カメラオペレーター + スイッチャー/音声 + 配信管理 の5名
- 想定用途: フラッグシップ店の世界観をブランド品質で配信

### 共通: 現地遠征費

- 現地までの往復交通費: 1名あたり概算
- 現地宿泊費: 1泊 × 人数（前日入り前提）
- 諸経費（タクシー・現地移動等）: 概算

## MCCMからのオリジナル依頼文（Slackやり取り抜粋）

```
お世話になっております！
12月下旬、フラッグシップ店舗が誕生します。
それにあたり、SNSでの大々的なにぎやかしをおこない、
そのにぎやかしプランに対し、メーカー様にご協賛いただくことを想定しています。

B1と2Fにかなり大きいPOPUPスペースを作るそうで、
@cosme名古屋店OPEN時に実施されていた現地でのライブ配信の様なことができそうですので、
それをベースにMCCでできそうなことを何か企画立案いただくことは可能でしょうか？？
6月末までにラフをいただけるとありがたいと思っております！
```

**佐藤様コメント**: 「いつもとは異なる環境でのライブ配信となります。
当社のみで配信を実施するということはオペレーション的に不可能だと思いますので、
貴社にディレクションいただく前提で企画のご検討をお願いできればと思います。」

**確定方針**: ミニマム/リッチの2パターンで企画＋見積もりを月末送付。

## 設計方針

1. **MTG（SIXPAD）案件のGAS・HTMLを踏襲**して骨格を作る
2. **遠征費セクションを新設**（旅費・宿泊・諸経費）
3. **メーカー協賛は別軸**として位置づけ、見積もりには協賛収益を含めない
   → 「MCCMがメーカー協賛で回収する原資の中から、Fireworkへ配信制作費を支払う」スキーム
4. **年間契約・割引行は不要**（1回限りの単発案件）
5. **デプロイ先**: firework-decks に SSO 付きで配置・社内限定共有
