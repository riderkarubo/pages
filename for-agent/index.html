Three Directions

関心の3方向

希望を1つに絞らず、3つの方向で整理しております。それぞれの方向に、ご提案いただいた中で関心を持った例を添えました。同種の座組でご紹介いただけますと幸いです。

DIRECTION 01

番組制作への回帰

「番組を作る現場に戻る」を最上位に置く方向。事業責任者から現場に近い座席への役割変更も、内容次第で前向きに検討いたします。

求めたい案件イメージ
  • TV局 / OTT / 配信プラットフォームの番組プロデューサー・ディレクター
  • バラエティ・音楽・ゲームジャンルの番組企画制作
  • 制作会社のリーダー / チーフPD（現場に近い座席）
DIRECTION 02

強みを転用した動画統括

事業責任者経験とプロデュース経験を活かし、メディア・ブランドの動画部門を統括する方向。演出と事業数字の両立が求められる座席をイメージしております。

ご提案の中で関心を持った例
マイベスト（動画プロデューサー / TikTok・Instagram / インハウス動画） メディアの動画部門を統括する座席。演出と事業数字の両立という点が既存の経験と重なります。
求めたい案件イメージ
  • メディア企業の動画統括プロデューサー / 責任者
  • 大手ブランドの動画・コンテンツ事業開発
  • ライブコマース事業の統括（既存の強みを転用）
DIRECTION 03

IP × ライブ の事業プロデュース

音楽・ゲームIPを軸に、映像・ライブ配信・イベントを統合するプロデュース方向。「音楽」と「長尺動画」というキーワードが最も濃く重なる領域です。

ご提案の中で関心を持った例
BMSG(オープンポジション) 音楽IPと長尺コンテンツを軸に事業を組み上げる方向性。これまでの経験と親和性が高いと感じます。
求めたい案件イメージ
  • 音楽レーベル / 事務所のコンテンツプロデューサー
  • ゲーム会社のライブ配信 / eスポーツプロデュース
  • IP × 映像 × ライブの統合プロデュース
