Three Paths

やってみたい仕事の3路線

私の希望は1つに絞れない代わり、3路線にきれいに畳めます。 石島さんから頂いた16社ご提案の中では、路線Bのマイベストと路線Cの BMSGが響きました。 各路線に該当する案件を、これらの企業と同じ座標で探していただければ幸いにございます。

ROUTE A

番組制作 純度路線

転職動機の原点。「番組を作る現場に戻る」を最上位に置く路線。 事業責任者からディレクター/プロデューサー職への役職ダウンシフトも許容します（年収レンジは維持前提）。

Past Reference
OPENREC（番組ディレクター・過去エージェント経由で検討） DONUTS傘下・オフラインイベント×番組×IPへピボット中。「番組制作の修行として2〜3年」の座組なら受ける価値ありと判断済み。
この路線で欲しい案件
  • TV局 / OTT / 配信プラットフォームの番組プロデューサー・ディレクター
  • バラエティ・音楽・ゲームジャンルの番組企画制作
  • 制作会社のリーダー / チーフPD（現場に近い座席）
ROUTE B

強み転用 × 高年収路線

事業責任者経験とプロデュース経験を活かし、メディア/ブランドの動画部門を統括する路線。 年収を維持〜向上させながら、コンテンツと事業を両輪で回す座席。

石島さんご提案で響いた企業
マイベスト（動画プロデューサー・TikTok/Instagram / インハウス動画） メディア×動画プロデュースの座席。ランキング比較というコンテンツ設計に、演出と数字の両方を要求される点が既存強みと直結。
この路線で欲しい案件
  • メディア企業の動画統括プロデューサー / 責任者
  • 大手ブランドの動画/コンテンツ事業開発
  • ライブコマース事業の統括（既存強み転用）
ROUTE C

IP × ライブ 事業路線

音楽 / ゲームIPを軸に、映像・ライブ配信・イベントを統合するプロデュース路線。 「音楽」と「長尺動画」という指定キーワードが最も濃く重なる領域。

石島さんご提案で響いた企業
BMSG（オープンポジション・SKY-HI率いる音楽レーベル） 音楽IPとオーディション番組（THE FIRST など）を長尺動画で束ねる作り方。私のプロデュース経験の全部が繋がる。
この路線で欲しい案件
  • 音楽レーベル / 事務所のコンテンツプロデューサー
  • ゲーム会社のライブ配信 / eスポーツプロデュース（※アニメ / Vtuber軸は除く）
  • IP × 映像 × ライブの統合プロデュース
Strengths
